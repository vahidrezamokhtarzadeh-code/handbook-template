# Project Narrative — Why the architecture is shaped this way

This is not a summary of decisions; it is the *cause* of their shape, so a new Chat/Engineer does not redesign past decisions based only on how the architecture looks.

## How to write this file

- One numbered section per "why" question that has a real causal story.
- Each section: triggering evidence/story → decision → reasoning → what was deliberately avoided.
- Reference the ADR/story/document where each decision lives.
- Never let a decision exist only here; it must also live in an ADR or `DECISION-TRACE.md`.
